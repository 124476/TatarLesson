## О проекте

TatarLesson — веб-платформа для изучения татарского языка, в которой учитель собирает уроки из интерактивных блоков, ученики занимаются по коду или в открытом доступе, а также соревнуются в турнирах по задачам.

Платформа объединяет три ключевых сценария:

- [x] Уроки — учитель создаёт урок из блоков за минуту, делится кодом с классом или публикует для всех.

- [x] Соревнования — отдельная система турниров с задачами, баллами, штрафами за попытки и Codeforces-style таблицей результатов.

- [x] Словарь — единая база татарских слов с переводом, транскрипцией и примерами, доступная всем.

## Возможности
### Уроки из блоков

Учитель собирает урок из 6 типов блоков, каждый настраивается из словаря:

| Блок             | Что делает                                           |
|------------------|------------------------------------------------------|
| Аудирование      | Ученик слушает слово (TTS) и вводит перевод          |
| Перевод          | Показывается татарское слово — нужен русский перевод |
| Собери слово     | Собрать татарское слово из букв по подсказке         |
| Найди пару       | Соединить татарские слова с русскими переводами      |
| Быстрый раунд    | Выбрать правильный перевод из вариантов              |
| Вставь пропуск   |  Дописать пропущенное слово в предложении            |

- Публичные и закрытые уроки. Публичный доступен всем (в т.ч. анонимам), закрытый — только автору и по коду.

- Вход по коду. Ученик вводит 6-значный код — и открывает урок.

- Анонимный режим. Публичный урок можно пройти без регистрации. Прогресс не сохраняется, но результат виден.

- AI-помощник. Генерирует набор блоков по теме.

- Разбор ответов. Опционально показывать правильные ответы после завершения.

### Соревнования
Отдельная система турниров с собственными задачами.

- 6 типов задач: текстовый ответ, один вариант, несколько вариантов, собери слово, найди пару, голосовой перевод.

- Автоподбор задач из словаря через встроенный picker (регистронезависимый поиск с татарскими буквами).

- Штраф за попытки. Правильная посылка с первой попытки — 100% баллов, каждая следующая — −20% (не ниже 20% от базовых).

- Повторная правильная посылка балл не понижает.

- Матрица результатов в стиле Codeforces: в ячейке — очки за решённую задачу или −N неверных попыток.

- Управление через админ-панель — создание, редактирование, публикация, удаление.

- Авторегистрация участника при заходе на соревнование.

## Словарь
Единая база татарских слов: tatar, russian, transcription, example_tt, example_ru, theme, level.

- 10 тем: семья, еда, животные, школа, природа, город, тело, цвета, числа, глаголы.

- Поиск по татарскому и русскому, фильтр по теме.

- Админ-CRUD прямо в дашборде.

- Озвучка слов (TTS) из карточки.

- Случайное слово на главной странице — с озвучкой и попыткой повторить голосом.

## Голосовые технологии
- TTS через TatSoft API — озвучка татарских слов и фраз (голоса alsu, almaz).

- ASR через TatSoft API — распознавание речи ученика.

- Морфология и перевод через TatSoft.

## Интерфейс и UX
- Тёмная и светлая темы с сохранением в localStorage.

- Адаптивный сайдбар в дашборде — сворачивается, работает на мобильных.

- Уведомления с long polling и маркировкой прочитанных.

- Чат поддержки — встроенный виджет.

- Личный профиль с аватаром и настройками.

- OAuth2 через Яндекс, GitHub, Google.

## Администрирование
- Django Admin на Unfold — современная админка.

- Inline-редактирование задач внутри соревнования.

- Разграничение прав: обычный пользователь / стафф.

## Технологии

- **Backend:** Django 5.1, Python 3.12
- **База данных:** PostgreSQL (поддержка SQLite и внешних URL)
- **Frontend:** Bootstrap 5, CSS-переменные, JavaScript (vanilla)
- **Голос:** TatSoft API (TTS, ASR, MT, морфология)
- **Хранение медиа:** локальное или Yandex Cloud Object Storage (S3)
- **Аутентификация:** django-allauth / social-auth (Яндекс, GitHub, Google)
- **Деплой:** Docker, Render
